# AnyOperate Target for Pi Pico W

This repository contains code that can be run on a Pi Pico W. It implements a configuration menu, that can be accessed via USB Serial, BLE or WLAN (Telnet). 

The configuration menu can be accessed using the AnyOperate Client App (available for Android currently).

# Building the Code
For Windows, examine the build.ps1 script, you will likely need to make changes to it to suit your environment.
